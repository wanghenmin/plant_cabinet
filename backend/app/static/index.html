On/off and brightness changes use the existing device interface. Observe the light and sensor readings, and avoid staring at a bright light for extended periods.

Pump Test

For hardware integration testing only. Firmware limits each run to 3 seconds and enforces a daily cumulative runtime limit.

Before testing, ensure the pump intake is submerged, the outlet tube is secured, and the power and water setup is safe. Reset clears the device watering interval and daily cumulative runtime; use it only for testing.

Automatic Watering Parameters

The soil start threshold allows watering when moisture is at or below the selected percentage. For example, with a 5% threshold, the reading must be 5% or lower. Automatic Watering must also be enabled and the settings saved.

Automatic Lighting Strategy

The device uses measured BH1750 lux to decide when to add light. Hysteresis prevents frequent switching near the threshold.

Manual mode takes priority over Automatic Lighting. The device resumes the lux strategy after you select “Restore Automatic Mode”.

Scheduled Lighting Strategy

The schedule runs locally on the ESP32 and continues to use saved settings if the network is interrupted.
